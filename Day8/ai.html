1. Text

Headings & Paragraphs

HTML provides six heading levels (h1–h6) and the humble <p> tag for paragraphs. Good typography starts with semantic structure.

You can mark text as bold, italic, underlined, or even struck through. For inline code: color: red;

4. Tables

Tables organise data into rows (<tr>), header cells (<th>), and data cells (<td>).

Tag Full Name Purpose Type
<p> Paragraph Block of text content Block
<a> Anchor Hyperlink to another resource Inline
<img> Image Embeds an image Inline
<table> Table Tabular data layout Block
<form> Form User input container Block
<div> Division Generic container / layout Block

CSS Concepts

6. CSS Selectors

CSS selectors target elements by element type, .class, or #id.

Selector Syntax Targets Example
Element p { } All <p> tags Every paragraph
Class .section { } All elements with class="section" These white cards
ID #site-header { } One element with id="site-header" The dark header above

7. CSS Box Model

Every HTML element is a rectangular box made of four layers: content → padding → border → margin.

Margin

Space outside the border

margin: 20px

Border

Visible edge around padding

border: 6px solid red

Padding

Space inside the border

padding: 32px 12px

Content

The actual text or media

width: 100%

Using box-sizing: border-box makes layout easier by including padding and border in width.
